# Shared Utilities

## Objectif
Ce dossier contient les utilitaires, configurations et bibliothèques partagés entre les différents microservices.

## Contenu
- **Utils** : Fonctions utilitaires communes (ex. : validation, gestion des erreurs).
- **Configs** : Fichiers de configuration centralisés (ex. : variables d'environnement).
- **Constants** : Constantes globales utilisées dans plusieurs services.

## Technologies
- Langage : TypeScript/Python (selon les besoins)
- Gestion des configurations : dotenv
